# 勤務開始の自動記録（start）

## 手順

### 1. 勤務形態（リモートまたは出社）の判定・確認

- ユーザーのチャット発言（例：「リモートで勤務開始」「本日出社しました」など）から、今日の勤務形態（`リモート`
  または `出社`）を特定する。
- **勤務形態の確認とフォールバック**:
  - ユーザーの発言に「リモート」や「出社」という情報が含まれていない場合は「リモート」で記録する。

### 2. 今日のおよび現在の情報を確認

- システム情報またはBashで今日の日付（`YYYY-MM-DD`）、曜日（月〜日）、および現在時刻（`HH:MM`）を確認する。

### 3. 今月の勤怠CSVを更新する

- 勤怠管理CSV `/Users/asaoyushi/Documents/10_事業(就活)/perfectbeer/YYYY-MM.csv`
  を読み込む。
  - ファイルが存在しない場合は、次のヘッダー行で新規作成する：
    `日付,曜日,勤務形態,開始,終了,休憩,実働時間,給与,交通費,備考・主なタスク`
- 今日の日付の行がすでに存在するか確認する。
  - 存在しない場合：末尾に新しい行として追加する。
    例：`YYYY-MM-DD,曜日,勤務形態,HH:MM,,,,,,` （※3列目に勤務形態を記録）
  - 存在する場合：すでに「開始」が書かれているか確認し、空であればその「開始」列に現在時刻（`HH:MM`）と「勤務形態」を書き込む。

### 4. デイリーノートを更新または作成する

- 今日のデイリーノート
  `/Users/asaoyushi/Documents/10_事業(就活)/perfectbeer/01_daily/YYYY-MM-DD.md`
  を読む。
- **ファイルが存在しない場合**： 以下の構造で新規作成する。
  ```markdown
  ---
  created: YYYY-MM-DD
  tags:
      - daily
  start: HH:MM
  location: 勤務形態（リモート または 出社）
  related:
  ---

  # YYYY-MM-DD
  ```
- **ファイルが存在する場合**： Frontmatter（先頭の `---` で囲まれた領域）に
  `start: HH:MM` および `location: 勤務形態` を追記または更新する。

### 5. ユーザーへ報告

- 勤務開始と勤務形態（リモート/出社）を記録した旨を伝える。
