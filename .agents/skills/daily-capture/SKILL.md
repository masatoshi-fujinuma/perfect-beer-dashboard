# デイリーノート追記（Chat → Daily）

## 手順

### 1. 今日の日付を確認

システム情報またはBashで今日の日付（YYYY-MM-DD）を確認する。

### 2. 今日のデイリーノートを読む

`01_daily/YYYY-MM-DD.md` を読む。

- ファイルが存在する場合：現在の内容を把握し、何が書かれているかを記憶する。
- ファイルが存在しない場合：新規作成として扱い、内容は空として進む。

### 3. チャット全体を振り返り、未記載の内容を抽出する

現在の会話コンテキスト（このチャット全体）を振り返り、デイリーノートにまだ書かれていない内容を特定する。
すでにデイリーノートに記載済みの内容は除外する。
追記すべき内容がなければ「追記すべき内容はありませんでした」と報告して終了する。

抽出した内容は以下の形式でまとめる。時刻は現在時刻を目安にする。

```
### HH:MM タイトル
- 内容
- 内容
```

また、内容に基づいて付与すべきタグを `../tags.md`（スキル共通）から選ぶ。
`tags.md`
にない語彙が必要な場合は、`../tags.md`（スキル共通）の適切なカテゴリに追加してからノートに使用する。

### 4. デイリーノートへ追記する

- ファイルが存在する場合：末尾に追記する。Frontmatter の `tags`
  に新たなタグがあれば追加する。
- ファイルが存在しない場合：以下の構造で新規作成する。`YYYY-MM-DD`
  は実際の日付に置き換える。

```
---
created: YYYY-MM-DD
tags:
  - daily
  - （内容に基づくタグ）
related:
---

# YYYY-MM-DD

### HH:MM タイトル
- 内容
```

追記後、ファイルパスを報告して完了。
